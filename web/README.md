### ⚙️ Установка проекта

1. **Склонируйте репозиторий**
   ```
   git clone https://github.com/AhmedLyanov/Kinoarea.git
   cd Kinoarea
   Установите зависимости
   ```

Серверная часть (/server):

```
cd server && npm install;
```

Клиентская часть (/client):

```
cd client && npm install
```

🛠 Настройка MongoDB
Установите MongoDB и запустите сервер (mongod).

Создайте базу данных Kinoarea (автоматически при первом подключении).

▶️ Запуск приложения
Сервер (из папки server):

```
node server.js
```

Клиент (из папки client):

```
npm start
```

🌐 Приложение будет доступно по адресу: http://localhost:3000
